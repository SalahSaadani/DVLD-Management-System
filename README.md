# 🚗 DVLD - Driving & Vehicle License Department System

A desktop management system built to streamline and automate the operations of a Driving and Vehicle License Department, including license issuance, renewals, replacements, test scheduling, and driver records management.

---

## 📋 Project Metadata
- **Project Type:** Desktop Application (Windows Forms)
- **Language & Framework:** C# (.NET Framework)
- **Database:** Microsoft SQL Server (T-SQL, Stored Procedures, Views)
- **Data Access:** ADO.NET (Parameterized Queries & Connection Pooling)
- **Architecture:** 3-Tier Architecture (Presentation Layer, Business Logic Layer, Data Access Layer)
- **UI Scale:** 20+ Windows Forms
- **Database Scale:** Normalized Relational Schema (13+ Tables)

---

## ✨ Key Features
- **People & Users Management:** Full CRUD operations for citizens' records, system users, and role-based permissions.
- **License Applications:** End-to-end workflows for New Local Driving Licenses, International Licenses, Renewals, and Replacements (Lost/Damaged).
- **Test Management:** Scheduling and recording results for Vision, Written (Theory), and Street (Practical) tests.
- **Detain & Release Licenses:** Managing detained licenses, fine calculations, and release workflows.
- **Data Integrity & Security:** Strict use of parameterized queries, stored procedures, and input validation to prevent SQL injection and ensure transactional consistency.

---

## 🏗️ System Architecture
The solution follows a clean **3-Tier Architecture** to separate concerns and improve maintainability:
1. **Presentation Layer (UI):** Windows Forms interfaces handling user interaction and input validation.
2. **Business Logic Layer (BLL):** Core domain rules, application workflows, and data processing.
3. **Data Access Layer (DAL):** Direct communication with SQL Server via ADO.NET, Stored Procedures, and Database Views.
